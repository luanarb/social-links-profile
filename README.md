💻 O que pratiquei

Neste projeto, pratiquei:

Estruturação semântica com HTML
Organização e estilização com CSS
Uso de variáveis CSS para as cores
Flexbox para posicionamento dos elementos
Estados :hover e :focus
Responsividade para diferentes tamanhos de tela
Navegação por teclado
Organização de arquivos e pastas

📱 Responsividade

O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela, incluindo as versões mobile e desktop propostas pelo desafio.

🎯 Desafio

O objetivo do desafio era criar uma página de perfil com links para redes sociais, reproduzindo o layout fornecido pelo Frontend Mentor e garantindo uma boa experiência em diferentes dispositivos.
